# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security vulnerabilities through the [Kaia Protocol Bug Bounty Program](https://hackenproof.com/programs/kaia-protocol) on HackenProof.

For general questions or non-security issues, open a [GitHub issue](https://github.com/kaiachain/kaia-system-contract/issues).
