# @kaiachain/system-contracts-klaytn-v1.0

Klaytn v1.0 system contracts.

## Contracts

| Contract          | Description                                       |
| ----------------- | ------------------------------------------------- |
| AddressBook       | Registry for node addresses and staking contracts |
| CnStakingContract | Consensus node staking contract                   |

## Installation

```bash
npm install @kaiachain/system-contracts-klaytn-v1.0
```

## Usage

```solidity
import "@kaiachain/system-contracts-klaytn-v1.0/contracts/AddressBook.sol";
import "@kaiachain/system-contracts-klaytn-v1.0/contracts/CnStakingContract.sol";
```

## Development

```bash
# Compile contracts
npm run compile
```
